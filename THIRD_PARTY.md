The behavioural reference is [Chance](https://scorsby.us/exp/chance/) at
[samscorsby/samscorsby.github.io](https://github.com/samscorsby/samscorsby.github.io/tree/4913a48eee128d201a01fdd2d3edc1074e0ec50a),
commit `4913a48eee128d201a01fdd2d3edc1074e0ec50a`, inspected on 2026-11-18.

No applicable license was found for `exp/chance`, its engines, publisher, or
`chance-trigger`. The unrelated `js/site-pet/LICENSE` does not license them.
This project uses independently authored code implementing the observed
structures and interaction model. It does not redistribute that source,
the author's mascot, recordings, album art, titles, or biography.
It is not a bit-identical fork of the reference engine.

The public artist identity and existing release artwork were verified from
[BELLACROSS Bandcamp](https://bellacrossmusic.bandcamp.com/). Original URLs and
verification dates are retained in `web/artist.json`.

The browser SHA-256 adapter is hash-wasm (MIT). Its bundled license is in
`web/vendor/hash-LICENSE.txt`. Python and npm dependencies retain their own
licenses. Exact direct versions and the npm lockfile are included. FFmpeg's
binary version is recorded with every generated album.
